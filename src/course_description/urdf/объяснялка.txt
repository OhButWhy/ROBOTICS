"body_length" - длина коробки
"body_width" - ширина
"body_height - высота
"body_mass" - масса
"body_z" - позиция по координате z

по этим параметрам собирается "base_link" - коробка, основное тело робота

"wheel_radius" - радиус колеса
"wheel_width" - толщина колеса
"wheel_mass" - масса

параметры используются для "${prefix}_wheel" - в проекте у нас две оси колёс - передняя и задняя, каждая со своим префиксом в названии, для каждой оси
пара колёс. То есть два front колеса и для rear колеса

"camera_x", "camera_y", "camera_z" - позиция камеры по координатам
эти координаты используются в "camera_joint" - сочленении камеры, чтобы соединить саму камеру "camera_link" с телом

"lidar_x", "lidar_y", "lidar_z" - позиция лидара, аналогично используется в "lidar_joint" для "lidar_link"

"knuckle_x", "knuckle_y" , "knuckle_z"  - позиция шарнира, используется в {prefix}_wheel_joint", то есть по сути это ось колёс

"imu_x", "imu_y", "imu_z" - позиция устройства измерения инерции, используется в "imu_joint" для "imu_link"

"box_inertia", "cylinder_inertia_y" - момент инерции для параллелепипеда и цилиндра, ориентированного вдоль оси y


- Rotation: in Quaternion (xyzw) [0.000, 0.000, 0.000, 1.000]
w = cos(θ/2)
x = axis_x * sin(θ/2)
y = axis_y * sin(θ/2)
z = axis_z * sin(θ/2)

где тета - угол поворота относительно оси (x, y, z), а axis_x,y,z - координаты оси в лабораторной системе
